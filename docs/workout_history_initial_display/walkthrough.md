# 修正内容の確認 (Walkthrough)

ワークアウト履歴の一覧が多すぎる問題を解決するため、初期表示を「当日の履歴のみ」に制限し、あわせてカレンダーの操作性を向上させました。

## 変更内容

### 履歴ページ (`pages/workouts/index.vue`)
- `selectedDate` の初期値を「今日」の日付（YYYY-MM-DD）に設定するように変更しました。
- これにより、ページを開いた直後に今日行ったワークアウトのみ（ない場合は空の状態）が表示されるようになり、データ量の多さによる混乱を回避しました。

### カレンダーコンポーネント (`components/WorkoutCalendar.vue`)
- 現在選択されている日付をハイライト表示（オレンジ色の塗りつぶし）する機能を追加しました。
- 今日が初期選択されるため、今月のカレンダーの中で今日がどの位置にあるかが一目で分かるようになりました。

## 検証結果

### 修正コードの動作
- 日付生成ロジックを `${year}-${month}-${day}` 形式に統一し、ブラウザの言語設定などに左右されない堅牢な動作を担保しました。
- カレンダーで別の日付をクリックすると、正しくフィルタリングが切り替わり、ハイライトも移動することを確認（コードベースでの確認）。
- 「すべて表示」ボタンにより、初期の当日フィルタを解除して全履歴へアクセスできる機能が維持されていることを確認。
